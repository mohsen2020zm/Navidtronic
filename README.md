# 🛒 E-Commerce Website (React.js)

A modern, responsive e-commerce web application built with **React.js**.  
This project includes product listing, product details, a shopping cart system, and a clean, user-friendly interface.  
It also uses several powerful libraries to enhance routing, form handling, validation, SEO, and UI experience.

---

## 🚀 Features
- 📱 Fully responsive and modern UI 
- 🔍 Product detail pages  
- 🛒 Shopping cart functionality  
- 🔐 Login & Register forms with validation  
- ⚡ High performance with optimized React components  
- 🎯 SEO enhancements using `react-helmet`

---

## 🧰 Technologies & Libraries Used

### Core
- **React.js**
- **JavaScript (ES6+)**

### Routing
- **react-router-dom** – For page navigation & route management

### Forms & Validation
- **react-hook-form** – Form handling and state management  
- **Yup** – Schema-based form validation  

### UI & Icons
- **react-icons** – Icon packs used throughout the UI

### SEO
- **react-helmet** – Manage page titles & meta tags

### Others
- Custom hooks, utilities, and reusable components

---

## 📦 Installation & Running

```bash
# Clone the repository
git clone https://github.com/mohsen2020zm/Navidtronic

# Navigate into the project folder
cd Navidtronic

# Install dependencies
npm install

# Start development server
npm start
# or
npm run dev
```
