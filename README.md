# Navidtronic

A modern electronics e-commerce website built with React, Vite, and Tailwind CSS.

Navidtronic is a frontend portfolio project designed to showcase a modern online shopping experience for electronic products. The website uses mock product data to simulate an electronics store and demonstrate frontend development skills.

## ✨ Features

- 🛍️ Electronics e-commerce interface
- 📦 Mock product data for displaying products
- ⚛️ Component-based architecture with React
- 🧭 Client-side routing with React Router DOM
- 🎨 Responsive styling with Tailwind CSS
- 📝 Form handling with React Hook Form
- ✅ Form validation with Yup
- 🔍 SEO metadata management with React Helmet
- 🎯 Icons from React Icons

## 🛠️ Technologies Used

- **React** — Building reusable UI components
- **Vite** — Development server and build tool
- **Tailwind CSS** — Utility-first CSS framework
- **React Router DOM** — Client-side navigation and routing
- **React Hook Form** — Form state management
- **Yup** — Schema-based form validation
- **React Helmet** — Managing document head and metadata
- **React Icons** — Icon library
- **JavaScript** — Application logic

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohsen2020zm/Navidtronic
   ```

2. Navigate to the project directory:

   ```bash
   cd Navidtronic
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   ```text
   http://localhost:5173
   ```

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 📁 Project Data

This project uses mock data to represent products in an electronics store. The data is intended for demonstration and testing purposes and does not represent real product listings, prices, or inventory.

No real product inventory or backend integration is implied.
